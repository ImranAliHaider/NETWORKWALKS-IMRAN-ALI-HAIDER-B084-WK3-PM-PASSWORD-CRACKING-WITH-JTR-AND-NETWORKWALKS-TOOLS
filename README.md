# Password Cracking – Week 3

This repository contains my Week 3 Cybersecurity Project Modules completed during my Networkwalks training.

## Project Modules

### Module 1: Password Cracking with JTR
- Download and install John the Ripper on Windows PC.
- Install and configure Johnny GUI.
- Extract the PDF hash.
- Test the password using JTR.

### Module 2: Password Cracking with Networkwalks Tools
- Use Networkwalks Hash Calculator.
- Extract the PDF hash.
- Use Networkwalks Password Cracker.
- Verify the recovered password.

## Tools Used
- John the Ripper (JTR)
- Johnny GUI
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Windows PC and Web Browser

## Purpose
The purpose of these tasks is to understand PDF password recovery and learn how password-testing tools work.
